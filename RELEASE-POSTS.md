# Beeb 0.10.9 hotfix announcement

Beeb's latest hotfix makes optional 4K setup much simpler: open Settings → Enable BBC UHD and connect directly on Apple TV. No computer helper, downloader, Python or copied setup link.

It also fixes Modern Topbar focus, adds a left-edge shortcut for the sidebar with return to the same item, makes Saved easier to reach from episode rows, and cleans up the Live page.

Download: https://github.com/usefulappmaker/Beeb-public/releases/tag/v0.10.9

The IPA is unsigned and needs your own signing before installation. Beeb is an independent, open-source BBC player for Apple TV.
